# Code Examples & Recipes

These snippets match the compiler's `examples/` folder in [Kyma](https://github.com/Up-to-code/Kyma). Standard-library functions are globals — no `import std.*`.

---

## 1. Structured logging

Prefer `slog*` over `print` in services:

```kyna
slogInfo("ready", { service: "kyna" });
slogWarn("slow");
slogError("failed", { code: "KNET" });
```

## 2. Queue + JSON

```kyna
const pending = createQueue();
enqueue(pending, "one");
enqueue(pending, "two");
const first = dequeue(pending);
const payload = jsonStringify({ first: first, empty: queueIsEmpty(pending) });
```

## 3. Stream a file copy

```kyna
try {
    createDirectory("scratch");
    writeFile("scratch/source.txt", "streamed");
    const copied = copyFile("scratch/source.txt", "scratch/dest.txt");
    slogInfo("copied", { bytes: copied });
} catch (failure) {
    slogError("copy failure", { code: failure.code, message: failure.message });
}
```

## 4. HTTP + parse IP

```kyna
try {
    const res = await fetch("https://api.kyna.dev/v1/users/1");
    if (res.ok) {
        const data = res.json();
        slogInfo("user", { name: data["name"], ip: parseIP("10.0.0.2") });
    }
} catch (err) {
    slogError("fetch failed", { code: err.code, message: err.message });
}
```

## 5. Package layout

```text
app/
  helpers.kyna
  main.kyna
```

```bash
ky check ./app
ky run ./app
```

Sibling files share one namespace. Put unstable helpers under `app/internal/` so other packages cannot import them (`KSEM1042`).

More runnable programs live in the compiler repo under `examples/standard_library/`, `examples/network/`, and `examples/learning/`.
