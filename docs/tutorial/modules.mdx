# Modules & Code Organization

As your codebase grows, you can split functionality across multiple files and import them using Kyna's module system.

---

## Importing Standard Modules

Kyna provides standard library modules under the `std` namespace:

```kyna
import std.fs;
import std.time;

const start = time.nowNs();
const exists = fs.exists("config.toml");
print("Config exists:", exists);
```

---

## Importing Local Project Modules

You can import functions, classes, and constants from other `.kyna` files in your workspace:

```kyna
# Importing from a local file 'utils/crypto.kyna'
import utils.crypto;

const hash = crypto.sha256("payload");
print("Hash:", hash);
```

---

## Exporting Members

All top-level `public` functions, classes, and constants in a module are available to importing files:

```kyna
# math_helpers.kyna
public fn add(a: int, b: int): int {
    return a + b;
}

public const PI: float = 3.14159265;
```
