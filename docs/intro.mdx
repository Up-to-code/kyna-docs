# Introduction to Kyna

Kyna is a modern, statically typed programming language engineered for building backend services, command-line tools, and high-performance scripts.

It combines clean, readable syntax with compile-time safety guarantees, a transparent 6-stage compiler pipeline, and an optimized bytecode virtual machine.

```kyna
# A complete Kyna script
fn greet(name: str): str {
    return "Hello, " + name + "!";
}

const user: str = "Developer";
print(greet(user));
```

---

## Why Kyna?

When building backend services and scripts, developers frequently have to choose between two extremes: the rapid prototyping velocity of dynamic languages, or the strict safety and execution performance of compiled languages. 

Kyna is designed to eliminate this tradeoff:

### 1. Compile-Time Safety Without Boilerplate
Kyna's static type checker verifies variable bindings, function signatures, and nullability before a single line executes. You get instant diagnostics in your terminal or editor rather than debugging unhandled runtime crashes in production.

### 2. Explicit Null Safety
Null reference exceptions are eliminated through explicit nullable types (`str?` vs `str`). The compiler forces you to handle missing values safely, with automatic type narrowing after null checks:

```kyna
fn findUser(id: int): str? {
    if (id <= 0) {
        return null;
    }
    return "User_" + id;
}

var result = findUser(42);
if (result != null) {
    # 'result' is automatically narrowed to 'str' here
    print("Found:", result);
}
```

### 3. Transparent 6-Stage Compilation Pipeline
Kyna doesn't treat compilation as a black box. You can inspect the intermediate representations at every stage of compilation using dedicated CLI flags:

| Stage | Command | Purpose |
| :--- | :--- | :--- |
| **Tokens** | `ky tokens app.kyna` | Scans source text into structured lexical tokens |
| **AST** | `ky ast app.kyna` | Builds and validates the Abstract Syntax Tree |
| **Type Check** | `ky check app.kyna` (or a directory) | Validates types, bindings, and control flow |
| **HIR** | `ky hir app.kyna` | High-Level Intermediate Representation |
| **MIR** | `ky mir app.kyna` | Mid-Level IR with control flow optimizations |
| **Bytecode** | `ky bytecode app.kyna` | Emits compact bytecode instructions |
| **VM Run** | `ky run app.kyna` | Executes bytecode on the lightweight VM |

### 4. Native Async Runtime & HTTP Networking
Asynchronous programming is a first-class language feature. You can perform non-blocking HTTP requests and JSON serialization with simple, intuitive syntax:

```kyna
async fn fetchStatus(service: str): str {
    try {
        const response = await fetch("https://api.kyna.dev/health/" + service);
        return jsonParse(response)["status"];
    } catch (err) {
        return "Offline: " + err;
    }
}
```
