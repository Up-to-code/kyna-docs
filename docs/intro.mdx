# Kyna documentation

Kyna is a statically typed programming language with a native CLI, an
inspectable compiler pipeline, and two execution paths: bytecode and a
tree-walk compatibility engine.

:::note Preview status
Kyna is under active development. Check the
[implementation status](https://github.com/Up-to-code/Kyna/blob/main/docs/implementation-status.md)
before using it in production.
:::

## Install

Install the current preview from the official npm organization:

```sh
npm install --global @kyna-language/cli@preview
ky --version
```

The installer supports macOS and Linux on x64/ARM64, and Windows on x64.

<details>
<summary>Use Bun or install directly</summary>

Allow Bun to run the checksum-verified native installation step:

```sh
bun add --global --trust @kyna-language/cli@preview
```

Install directly on macOS or Linux without Node.js:

```sh
curl -fsSL https://github.com/Up-to-code/Kyna/releases/download/v1.0.0-preview.3/install.sh | sh -s -- --channel preview --version 1.0.0-preview.3
```

Install directly with Windows PowerShell:

```powershell
& ([scriptblock]::Create((irm 'https://github.com/Up-to-code/Kyna/releases/download/v1.0.0-preview.3/install.ps1'))) -Channel preview -Version 1.0.0-preview.3
```

The Bun package path currently requires Node.js 18+ for the command shim. The
direct installers do not require Node.js.

</details>

## First program

Create `hello.kyna`:

```kyna
fn greet(name: str): str {
    return "Hello, " + name;
}

const language = "Kyna";
print(greet(language));
```

Run it:

```sh
ky run hello.kyna
```

Check it without executing:

```sh
ky check hello.kyna
```

## Core ideas

### Types are explicit when they matter

Kyna can infer simple types, while annotations document and enforce public
contracts. Types are non-nullable by default; add `?` when a value may be
`null`.

```kyna
var nickname: str? = null;
```

### Mutability is visible

Use `var` for a binding that can change and `const` for one that cannot.

```kyna
var attempts = 0;
attempts = attempts + 1;

const limit = 3;
```

### Compiler stages are inspectable

The `ky` CLI exposes the compilation pipeline instead of hiding it:

| Stage | Command |
| --- | --- |
| Tokens | `ky tokens app.kyna` |
| Syntax tree | `ky ast app.kyna` |
| Type checking | `ky check app.kyna` |
| HIR | `ky hir app.kyna` |
| MIR | `ky mir app.kyna` |
| Bytecode | `ky bytecode app.kyna` |
| Execution | `ky run app.kyna` |
