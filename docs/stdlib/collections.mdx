# Standard Library: Collections

Kyna provides built-in lists (dynamic arrays) and maps (hash tables) for data storage, transformation, and retrieval.

---

## List Operations

Lists are dynamic zero-indexed sequences:

```kyna
var tasks = ["init", "build", "test"];

# Length
print(len(tasks)); # 3

# Appending elements
tasks.push("deploy");
print(len(tasks)); # 4

# Index access
print(tasks[0]); # "init"
print(tasks[3]); # "deploy"
```

### Common List Methods & Helpers

| Method / Helper | Description | Example |
| :--- | :--- | :--- |
| `list.push(item)` | Appends item to the end | `tasks.push("doc")` |
| `list.pop()` | Removes and returns the last element | `const last = tasks.pop()` |
| `list.contains(val)` | Checks if item exists in list | `tasks.contains("build")` |
| `list.clear()` | Removes all elements from list | `tasks.clear()` |

## Map / Dictionary Operations

Maps store key-value pairs with fast hashing lookups:

```kyna
var config = {
    "env": "production",
    "port": 8080,
    "ssl": true
};

# Reading values
print(config["env"]); # "production"

# Modifying values
config["port"] = 9000;
print(config["port"]); # 9000

# Checking key existence
if (config.hasKey("ssl")) {
    print("SSL is explicitly configured");
}
```

## Functional Iteration Patterns

```kyna
fn filterPositive(numbers: int list): int list {
    var filtered: int list = [];
    loop (var i = 0; i < len(numbers); i = i + 1) {
        if (numbers[i] > 0) {
            filtered.push(numbers[i]);
        }
    }
    return filtered;
}

const data = [-10, 5, 0, 42, -3, 99];
print(filterPositive(data)); # [5, 42, 99]
```
