# Standard Library: System & Process

The system module provides access to environment variables, command-line arguments, operating system metadata, and process controls.

---

## Environment Variables

Access host environment variables using `processEnv()`:

```kyna
const port = processEnv("PORT");
const envMode = processEnv("NODE_ENV");

print("Configured port:", if (port != null) port else "8080");
print("Running in mode:", if (envMode != null) envMode else "development");
```

---

## Command-Line Arguments

Read arguments passed to the script via `processArgs()`:

```kyna
const args = processArgs();

# args[0] is the interpreter / executable path
# args[1] is the script path
# args[2+] are user-supplied arguments

if (len(args) > 2) {
    print("First argument:", args[2]);
}
```

---

## Process Control & Exits

```kyna
# Exit the current process with a status code
if (errorEncountered) {
    processExit(1); # Exit with failure
} else {
    processExit(0); # Normal clean exit
}
```
