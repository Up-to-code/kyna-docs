# Timing and memory

Measure work and inspect garbage collection.

## Timing

`clockMs()` returns monotonic milliseconds; `measure(fn)` runs a zero-argument
function and returns the elapsed time so any computation can be timed:

```kyna
fn accumulate(): int {
    var total = 0;
    loop (var i = 0; i < 20000; i = i + 1) {
        total = total + i;
    }
    return total;
}

var start = clockMs();
var result = accumulate();
profileLog("accumulate-by-clock", clockMs() - start);

var elapsed = measure(accumulate);
print("result", result, "measure-ms", elapsed);
```

- `clockMs()` — monotonic milliseconds;
- `measure(fn)` — run a callable and return elapsed milliseconds;
- `profileLog(label, value)` — emit a profiling line.

## Memory

```kyna
collectGarbage();
print(gcStats());
```

- `collectGarbage()` — force a collection;
- `gcStats()` — current garbage-collection statistics.

:::tip

Builtins that take significant time are measurable by design: wrap the work in
a thunk and call `measure(thunk)` to record elapsed time, then `profileLog(...)`
to emit it.

:::
