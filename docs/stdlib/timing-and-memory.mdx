# Standard Library: Timing & Performance

The `std.time` module provides high-resolution timers, epoch timestamps, and sleep utilities for benchmarking, timeouts, and metrics.

---

## High-Resolution Benchmarking

```kyna
import std.time;

# Measure nanoseconds
const startNs = time.nowNs();

# Perform intensive calculation
var total = 0;
loop (var i = 0; i < 100000; i = i + 1) {
    total = total + i;
}

const elapsedNs = time.nowNs() - startNs;
const elapsedMs = elapsedNs / 1000000;

print("Execution time:", elapsedMs, "ms (", elapsedNs, "ns)");
```

---

## Standard Timestamps & Sleep

| Function | Signature | Description |
| :--- | :--- | :--- |
| `time.nowMs` | `time.nowMs(): int` | Milliseconds since Unix epoch |
| `time.nowNs` | `time.nowNs(): int` | Nanoseconds for precision benchmarks |
| `time.sleep` | `time.sleep(ms: int): void` | Pauses execution for `ms` milliseconds |

```kyna
import std.time;

print("Starting task...");
time.sleep(1000); # Pause for 1 second
print("1 second elapsed.");
```
