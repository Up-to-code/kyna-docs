# Standard Library: Filesystem (`std.fs`)

The `std.fs` module provides synchronous and asynchronous file system operations for reading, writing, inspecting, and deleting files and directories.

---

## File Operations

```kyna
import std.fs;

# Reading files
const content = fs.readString("config.json");
print("File content length:", len(content));

# Writing files
fs.writeString("output.log", "Log entry at startup\n");

# Appending to files
fs.appendString("output.log", "Worker #1 ready\n");
```

---

## Path & Directory Operations

| Function | Signature | Description |
| :--- | :--- | :--- |
| `fs.exists` | `fs.exists(path: str): bool` | Checks if a file or directory exists |
| `fs.isFile` | `fs.isFile(path: str): bool` | Returns true if path is a regular file |
| `fs.isDir` | `fs.isDir(path: str): bool` | Returns true if path is a directory |
| `fs.mkdir` | `fs.mkdir(path: str): bool` | Creates directory |
| `fs.remove` | `fs.remove(path: str): bool` | Deletes file or directory |
| `fs.readDir` | `fs.readDir(path: str): str list` | Lists all entries in directory |

---

## Safe File Reading with Error Handling

```kyna
import std.fs;

fn loadSecret(path: str): str? {
    if (!fs.exists(path)) {
        print("Warning: Secret file not found at:", path);
        return null;
    }

    try {
        return fs.readString(path);
    } catch (err) {
        print("Error reading file:", err.message);
        return null;
    }
}
```
